# AgZen

> AgZen is an MIT spinout building RealCoverage, a sensor- and AI-based system that measures and controls how many droplets of crop-protection product land on every leaf during agricultural spraying. A boom-mounted computer-vision sensor analyzes spray coverage and droplet quality in real time and displays actionable data on an in-cab tablet, automatically optimizing foliar sprays on any sprayer as the operator drives, cutting chemical and water use by up to 50%.

AgZen is a physical ag-tech hardware and services company. As of this writing it publishes no public API, developer portal, OpenAPI specification, SDK, or MCP server; this llms.txt is generated from the API Evangelist catalog profile rather than a provider-published document.
